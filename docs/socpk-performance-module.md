# SOC PK 性能对比模块

本次按照 [SOC PK](https://www.socpk.com/) 的公开项目分类与数据完善性能对比。维持橙色界面、较大字体与明确按钮，默认打开手机 / 平板榜单，桌面入口继续使用既有 Geekbench Browser 数据。

## 数据与口径

`apps/web/src/data/socpkCatalog.json` 是 2026-11-01 获取的本地快照，包含 12 张来源图表、1,216 条来源系列记录，其中曲线共有 17,237 个来源提供点。系列包括不同项目、核心、版本和设备配置，**不代表 1,216 款不同芯片，也不全部是未经拟合的原始实测点**。

| 平台 | 曲线 / 排名 | 使用规则 |
| --- | --- | --- |
| 手机 / 平板 CPU | SPEC CPU 2026 INT、FP | 分开负载，保留每个系列的核心名称 |
| 手机 / 平板 CPU | Geekbench 6、Geekbench 7 多核 | 按来源 `meta.suite` 分表；网址含 gb7 不代表其所有数据都是 GB7 |
| 手机 / 平板 GPU | 3DMark Steel Nomad Light | 使用来源主板功耗口径，非单独 GPU 芯片耗电 |
| 笔记本 GPU | 3DMark Time Spy | 不与同名桌面显卡直接混用；最高来源功耗点排名说明各型号上限不同 |
| 历史项目 | SoC 综合、CPU 综合、GPU 综合、CPU 能效指数、GB5/GB6 单多核、GFXBench 5 1080p/1440p、Wild Life Extreme | 明确历史属性、原单位与来源计算方式，不用任意分数重新构造综合榜 |
| 桌面 CPU / GPU | 原有 Geekbench 7 单多核、OpenCL | 保留原数据来源，不把 SOCPK 移动曲线拼到桌面硬件记录 |

手机曲线的功耗按来源说明为主板口径，已扣除屏幕；它不等于芯片单独功耗、整机续航或标称 TDP。SPEC 分数、GB 分数、图形帧率和相对指数不能混排。CPU/GPU 综合指数保留来源榜单结果；页面没有拿本地 GB7 跑分代入历史权重公式重算。

来源数据带 `fitted` 标记时原样保留。页面按照提供点画线，点间只作线性插值，不重新制作来源的曲线拟合模型。超过任一系列的最小/最大功耗时比较结果留空。最高来源功耗点成绩也不视为统一配置的独立峰值实测。

## 交互

- 平台、CPU/GPU、榜单/曲线和测试项目分别选择；切换上下文清除旧选择与品牌筛选。
- 支持中文/英文型号、核心、品牌搜索，品牌筛选，榜单分页展开。
- 最多选 6 条系列，默认曲线选择 3 条来源推荐记录；不同核心用来源 ID 区分，避免同名合并。搜索隐藏的已选条目仍参与比较。
- 曲线支持性能 / 每瓦性能、功耗范围缩放条、重置缩放、全屏、同功耗数值比较、来源点详情。
- 排名显示原分数和单位，柱形以当前项目最高成绩为 100%；选中后可以更换基准型号查看相对百分比。
- 排名全图由当前数据生成，图片与列表共用相同分数，并保留缩放、拖动功能。
- 对比选择、测试项目、功耗与每瓦视图写入网址，可复制链接。清空选择后刷新不会自动恢复默认的 3 条曲线。
- 导出比较表 CSV 和来源点 CSV，包含项目、来源、日期、来源版本与拟合标记；文本做 CSV 转义及公式前缀处理。
- SOC PK 数据按需载入，压缩传输约 142 KB；访问桌面或其他页面不必加载快照。不在用户打开页面时跨站抓取数据。

## 来源与更新

公开来源页面为 `https://www.socpk.com/chart/<slug>`，每张图记录原站版本及公开数据响应的 SHA-256。具体来源已保存在 JSON 和页面的“核对原始资料”链接中；没有使用原站品牌图片或复制其站点 UI 源代码。

更新命令：

```powershell
python tools/import_socpk_data.py --refresh
python tools/audit_project_data.py --database apps/api/zhixiu_dev.db
```

导入器仅请求公开页面及页面所用公开数据接口。用原站公开客户端提供的 WASM 格式解码器解释响应，不执行下载的 JavaScript、不调用管理接口、不登录、不将临时令牌或站点程序打包到本项目。解码工具 `tools/socpk_decode.cjs` 使用无宿主导入的 WASM 实例。

更新前后必须检查数据差异。导入器在来源版本、系列 ID 或点序校验失败时停止，不覆盖已有快照。来源未来变更结构、单位或测试版本时，需要重新人工核对映射。`retrieved_at` 为取得快照的日期，不冒充原站测试或更新日期；页面说明数据并非实时排名。

为降低公开序列化格式恢复产生的浮点尾差，数值保留至四位小数；距整数小于 0.0001 的值恢复为整数。未添加来源没有提供的功耗点。
