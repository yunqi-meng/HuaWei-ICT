# 界面与交互修复记录

验证日期：2026-11-01。本次修改用于本地开发版本。

## 修复内容

| 范围 | 原问题 | 当前行为 |
| --- | --- | --- |
| 天梯图 | 超长图片以中心缩放，图片偏移；拖动无边界；滚轮可能滚动页面 | 按视窗适配全图，提供适应宽度；围绕指针缩放；限制拖动边界；支持指针捕获、触摸双指和键盘操作 |
| 能耗曲线 | 在数据范围外补出零瓦曲线和高功耗平台；横轴按分类间距绘制 | 使用数值功耗轴，保留各型号功耗端点，仅在已有范围内线性插值，范围外留空 |
| 曲线指标 | 详情页性能分与每瓦性能共用刻度 | 分别使用左右纵轴；性能页提供性能与每瓦性能切换 |
| 型号选择 | 分类切换残留型号；型号重复；六款上限没有反馈 | 分类切换清除旧选择，过滤非法 URL 参数和重复选择，明确上限与空态；选项和模式可通过 URL 恢复 |
| 硬件对比 | CPU/GPU 混选导致指标失真；不存在型号返回成功状态 | 前后端均限制同类型对比，校验 2–6 款不同型号；不存在型号返回 404，非法组合返回 400 |
| 数据请求 | 快速筛选时旧响应覆盖新结果，部分失败被当成空数据 | 可取消的资源请求，忽略过期响应，明确区分加载、空数据和失败，支持重试及搜索防抖 |
| 问题求助 | 用定时器返回固定建议，没有创建诊断会话 | 接入现有诊断 API；登录跳转保留故障描述；创建成功后进入正式排障流程 |
| 直接预约 | 首页入口缺少工单编号时进入报错死路 | 提供故障表单，先创建工单再进入活动与时段选择；失败重试复用幂等键 |
| 诊断与交接 | 交接请求缺少异常处理；旧 SSE 状态可能覆盖新版本；弹窗内看不到提交失败原因 | 请求状态和异常反馈完整，按版本接受 SSE；提交错误在弹窗内显示；支持焦点约束和 Escape 关闭 |
| 维修台 | 快速切换工单时详情可能错位；录入内容带到其他工单；重复提交缺少保护 | 取消旧详情请求，切换工单清理维修表单，操作中禁用重复提交 |
| 设备与账号 | Linux 默认版本误填 macOS；验证码和退出反馈不完整 | 正确设置系统默认版本；验证码发送冷却及操作状态；退出失败保留反馈，过期会话允许退出 |
| 后台管理 | 筛选请求竞态、日期范围无前端反馈、部分排班失败后容易重复建活动 | 独立刷新统计与工单，校验日期范围，提供账号搜索；活动创建成功即清空创建标题，部分排班失败时保留草稿并指引补充排班 |

## 视觉与可用性

- 统一配色、字体层级、卡片、按钮、表单、表格、状态提示与页脚。
- 重做首页，使用项目内 SVG/CSS 绘制图形，无新增外部字体和图片请求。
- 全站使用统一导航；服务及硬件页面提供相关功能导航；增加移动菜单和当前页提示。
- 用户页、预约页、维修台和后台页面共用一致的标题与布局；表格在窄屏内滚动。
- 登录和预约表单支持标准表单提交；字段关联标签，交互提供焦点样式，尊重减少动画设置。
- 做工卡片改为明确的展开按钮，移除图片失败时直接改写 DOM 的处理；增加搜索与排序。
- 页面按路由懒加载，首页不预加载图表页面代码。

### 橙色主题与字号调整

按后续要求将全站改为暖橙色：使用橙色主按钮、浅橙背景与深棕文字，首页插画、导航、表单、卡片和后台页面同步调整。正文采用桌面 17px、手机 16px，表单文字为 17px，主要辅助说明为 14–15px；品牌副标题和装饰插画保留独立的字号层级。

主要按钮字号提升至 16–17px，按钮高度通常为 48px，图标操作通常为 44px。文字操作增加浅橙底、边框和悬停反馈；首页服务卡片改为实心与描边按钮组合，快捷入口保留醒目箭头；指南卡片增加“阅读指南”文字入口。当前导航和选中标签用实心橙色明确标识。

对 390px、768px、1440px 下的公开页面进行浏览器检查，另检查登录后的服务和后台页面。移动导航改为两列展开，表格、筛选和操作栏随更大字号调整布局。

## 验证方式

最终结果：前端 7 个测试文件共 30 项测试通过；后端 69 项测试通过；TypeScript 与 Vite 生产构建通过；`git diff --check` 通过。

```powershell
cd apps/web
npm test
npm run build

cd ../api
python -m unittest discover -s tests -q
```

前端回归覆盖：缩放数学与边界、功耗插值、六个分类数据唯一性、请求取消与重试、性能页选择与切换、直接预约、问题求助、诊断 SSE 版本与交接错误反馈，以及原有预约恢复和改期测试。

后端回归覆盖：现有业务测试，以及新增的硬件 404、非法类型、混合对比、重复型号、数量上限、顺序与排行榜指标测试。测试使用独立数据库，禁用真实模型调用。

使用 Tabbit 在本地实际浏览器中检查了 22 条公开及登录后路径，包括首页、求助、天梯、曲线、做工、指南、硬件库/排行/对比/详情、登录、我的服务、设备、账号、通知、预约、维修台、运营、排班、编审和系统管理。390px 宽度下未发现页面横向溢出；已验证页面没有触发错误边界。

额外实测：全图边界、滚轮缩放不滚动页面、双指缩放、键盘 +/Home、移动菜单自动收起、曲线悬浮数值、普通用户访问后台时的权限提示。测试结束恢复未登录首页。
