# 前端 UI 与交互升级验收记录

## 范围与技能

本轮在当前工作目录的已有实现上继续修改，采用本机 `frontend-design` 技能制定视觉规范，使用 `tabbit` 技能执行真实浏览器检查。设计方案见 `docs/frontend-experience-plan.md`。

覆盖全部现有页面组件：主页、登录、求助、排障、预约、服务记录与工单详情、设备、账号、通知、指南与详情、硬件数据库/排行/天梯/全量规格/芯片详情/芯片对比/主板/做工/性能对比，以及维修、运营、排班、编审和系统管理。通用标题、按钮、表单、反馈、表格、弹窗与来源说明使用统一的语义色和布局规范。

## 主要变化

- 视觉采用深蓝导航、冷白内容和青蓝操作色；另有可记忆的深色主题。中文使用系统无衬线字体，数字使用等宽数字表现；未引入外部字体或图片网络依赖。
- 宽屏常驻侧栏集中呈现公共、个人和角色管理入口；手机改为可关闭的导航抽屉，包含 Escape、焦点循环与背景滚动锁定。
- 增加 Ctrl/Cmd + K 快捷跳转、关键词过滤、方向键选择和 Enter 打开；管理入口按当前角色筛选。保留服务端原有权限校验。
- 首页增加可切换的服务路径预览和问题输入，可把描述带到求助页面；路径预览不表示诊断已经执行。
- 登录页改为双栏布局，增加密码显隐及大写锁定提示，保留错误后的输入和原始返回路径。
- 设备页改为编辑与列表分栏，新增保存反馈、空/失败状态、删除确认和失败后重试；关联业务的设备仍由后端禁止删除。
- 服务记录增加工单标题搜索和进行中/已结束筛选；排障与预约增加依据真实状态生成的进度提示。
- 排障反馈选项改为有明确选择边界的按钮组，人工出口单独呈现；加载、失败、空状态和成功反馈统一处理。
- 硬件、主板、做工、指南和性能页统一筛选、规格卡、比较托盘与图表配色；导出的天梯图使用同系冷色。原始规格、成绩、缺失值和来源口径保持不变。
- 数据表增加可聚焦的横向滚动区域；弹窗渲染到独立 portal，保留焦点约束与恢复；减少动画偏好受到尊重。
- 运营概览突出真实服务指标和状态筛选；系统管理将运行概况与待处理事项结构化，技术明细按需展开。
- CSS 基础布局放入独立层，主题与组件规范由 `workspace.css` 管理，减少历史选择器相互覆盖。

## 预览与边界

本地预览为 `http://127.0.0.1:15174`，API 为 `http://127.0.0.1:18100`，仅监听回环地址。预览使用 `artifacts/ui-preview-2026-11-11.db` 隔离演示库；实际数据库、原有联系人与工单未改写，未调用付费模型。

预览中可使用 README 中的开发账号检查角色页面。`停止项目.bat` 可停止这组一键入口管理的 API、Worker 与 Web。需要运行原业务库时，先停止预览，再按运行维护文档启动；预览的演示种子设置仅存在于预览进程环境，未更改本地 `.env` 的 `AUTO_SEED=false`。

首页第一轮截图已实际查看并据此调整字体、字号和层级，保存为 `artifacts/ui-home-desktop-initial.png`。Tabbit 最终截图接口连续超时；独立无头浏览器截图备选又被自动审批以“策略阻止”拒绝，因此没有交付最终版截图。上述浏览器布局与交互记录均为实际执行结果，不能将它们描述为所有页面均已人工截图验收。

构建仍提示原有全量硬件数据分块较大；本轮没有隐藏该警告或删减数据。真实场地、人工知识审核、独立评测、邮件及 OBS 联调仍沿用上轮明确的验收边界。
